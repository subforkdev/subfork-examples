# Event Example Instructions

- Distinguish event data, execution triggers, conditions, and externally visible
  actions in names and notes.
- Do not describe a manually run graph as scheduled, subscribed, or webhook-driven.
- Keep public event feeds bounded and preserve source dates, identifiers, and URLs.
- Make notification, messaging, device-control, and other external writes explicit;
  document retries and duplication risks and never run them during validation.
- Calendar examples must state timezone and recurrence limitations and must not
  embed private calendar URLs or credentials.
