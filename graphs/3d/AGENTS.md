# 3D Example Instructions

- Keep scene descriptions bounded and data-driven; avoid unbounded geometry or
  animation work during graph execution.
- Prefer graph-owned scene data over embedded scripts and remote runtime assets.
- Document coordinate systems, units, sampling, and visual encodings.
- Test both the graph output and its rendering in 3D Preview.
- Tag 3D graphs with 3d and a concrete scene, data, or media domain.
